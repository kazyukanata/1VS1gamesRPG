# 魔王 vs 勇者（2人対戦RPG）

スマホ1台を交互に操作する非対称対戦RPG。`index.html` 1枚で動作します。

## GitHub Pagesで公開
1. このフォルダの中身をリポジトリのルートにアップロード
2. Settings > Pages > Branch を `main` / `(root)` にして Save
3. 発行されたURLをスマホで開く

## 操作
- タイトル画面をタップ→ターン数(10/20)を選択→ルール説明→ゲーム開始
- 基地内は画面のどこでもドラッグ(仮想スティック)で移動、NPCの隣でタップして会話
- 行動回数は両軍とも1ターン2回(温存で最大3回)。同じ行動は1ターンに1回まで
- 商人での品定めは、その場ではなく次の勇者ターン開始時に行われます

## 今回まだ入っていない機能
- 開拓屋・コレクター・採石場/訓練場タイル・宝石の色分けと使い道（ベースの宝石カウントのみ実装）
