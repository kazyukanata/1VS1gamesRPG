# 魔王 vs 勇者（2人対戦RPG）

スマホ1台を交互に操作する非対称対戦RPG。`index.html` 1枚で動作します。

## GitHub Pagesで公開
1. このフォルダの中身をリポジトリのルートにアップロード
2. Settings > Pages > Branch を `main` / `(root)` にして Save
3. 発行されたURLをスマホで開く

## 操作
- タイトル画面をタップ→ターン数(10/20)を選択→ルール説明→ゲーム開始
- 基地内は画面のどこでもドラッグ(仮想スティック)で移動、NPCの隣でタップして会話
- 行動回数は両軍とも1ターン2回(温存で最大3回)。同じ行動は1ターンに1回まで
- 商人での品定めは、その場ではなく次の勇者ターン開始時に行われます

## 今回追加した機能
- 勇者側NPC「開拓屋」：街の開拓(村/街の出現率+5%、繰り返すほど積み重なり、未訪問マスにも反映)／採石場の強化／訓練場の強化(各Lv1〜5)
- 勇者側NPC「コレクター」：宝石と5種のアイテムを交換(各アイテムは1回まで)
  - 木こりのにんぎょう(3個)：次のトラップを1回回避
  - へんげの杖(4個)：次の召喚モンスターのレア度を1段階下げる(自動発動)
  - 2倍増幅剤(5個)：次の戦闘(最終戦除く)で攻撃・防御が2倍
  - けむり玉(4個)：次の戦闘(最終戦除く)を50%の確率で回避(報酬なし)
  - 馬車(15個・永久)：仲間の上限が5になる
- MAPに採石場マス(Lvに応じ宝石2〜6個)・訓練場マス(Lvに応じ攻撃力/最大HP上昇)を追加。結果は次の勇者ターン開始時に表示
